# 전설·환상 전용 BGM 미리듣기 · 검수 체크리스트 (BOSS_BGM.md B6)

미리듣기 = **인트로 → 1페이즈(16마디) → 라이저 → 2페이즈 → …** 를 이어 붙인 것 (게임에서 페이즈가 바뀌는 순서 그대로).
**쾌감 손질판** (DESIGN.md 43-12): 미는 박(킥·스네어·하이햇), 16마디 안에서 쌓아 올리기 + 크래시·필인, 빠른 낮은 오스티나토, 엇박 금관(전설)·16분 벨(환상), 킥마다 숨 쉬는 바탕.
게임 안에서는 **설정 → 접근성 → 테스트: 전설·환상 음악** 에서 곡·페이즈를 골라 위기·지침·실패·성공까지 바로 들어 볼 수 있어요.

## 직접 들어 볼 체크리스트

- [ ] 전설 곡을 들으면 "이 낚시터의 주인과 싸운다"는 **비장함**이 느껴지는가
- [ ] 환상 곡을 들으면 숨이 멎을 듯한 **황홀함**이 분위기를 압도하는가
- [ ] 전설·환상을 연달아 들었을 때 귀만으로 구분되는가 (전설 = 단조·금관·북 / 환상 = 리디안·하프·벨·합창 "아—")
- [ ] 게임 안에서: 소리가 커도 **신호 소리와 릴 소리**가 들리는가 (특히 '풀기' 신호 — 가장 작은 신호)
- [ ] 폰 스피커로 들어도 시끄럽기만 하지 않은가
- [ ] 페이즈가 바뀔 때 라이저가 자연스러운가, 지칠 때 주선율이 한 옥타브 올라가는 게 들리는가
- [ ] 전설을 잡으면 파이팅 곡이 같은 조성의 '전설의 노래'로 이어지는가 / 환상은 정적 뒤 '환상의 노래'
